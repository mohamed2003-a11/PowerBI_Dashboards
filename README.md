## Projects Overview

1. Data Professional Survey Project (Data Professional Survey Project.pbix)
- Objective: Analyzed global survey responses from data professionals to extract key insights into salaries, job satisfaction, work-life balance, and entry-level programming preferences.
- Key Tasks: Cleaned and unpivoted raw survey data in Power Query, built explicit column hierarchies, and established 1-to-many dimensional data models.
- Features: Interactive KPI cards, stacked bar charts, field parameter slicers, and dynamic drill-downs.

2. Visualizations & Design Gallery (Dashboard Design & Visualizations Gallery.pbix)
- Objective: Demonstrates advanced formatting, custom visual layouts, and interactive analytical features.
- Key Features: Formulated context-aware DAX calculations (SUMX vs. SUM comparison patterns), created field parameters for dynamic measures, and built custom category groupings.

3. Data Cleaning using Power Query (Data Cleaning useing PQ editor.pbix)
- Objective: End-to-end data transformation and ETL pipeline built inside Power Query Editor.
- Key Tasks: Handled missing/null values, changed data types, merged and appended queries, trimmed whitespace, and generated custom conditional columns.

---

## Technical Skills Demonstrated
- Power Query (ETL): Advanced transformations, query merging/appending, custom columns, and data hygiene.
- Data Modeling: Star schema design, relationship cardinalities (1:N), and cross-filtering direction.
- DAX Formulas: Calculated columns, measures, iterator functions (SUMX), and filter context modifiers.
- UI/UX Design: Clean layouts, conditional visual indicators, custom color palettes, and intuitive report navigation.
